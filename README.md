# Portfolio Website

A clean and responsive personal portfolio website built to showcase my skills, projects, experience, education, and contact information.

## Live Demo

[View Portfolio](https://nitheesh-mb.vercel.app)

## About

This portfolio represents my work as a software developer with an interest in full-stack web development. It includes sections for my technical skills, featured projects, internship experience, education, and contact details.

## Features

- Responsive design for desktop and mobile devices
- Smooth navigation across portfolio sections
- Project showcase with live demo and GitHub links
- Experience section with certificate links
- Skills section with modern technology icons
- Contact form UI
- Clean folder structure for GitHub deployment

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- EmailJS
- Particles.js
- ScrollReveal
- VanillaTilt.js
